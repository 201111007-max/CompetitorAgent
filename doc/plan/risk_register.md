# 风险登记表（Risk Register）

> 竞品分析 Agent 实现与运行期的风险清单。每项含：影响 / 概率 / 缓解措施 / 状态。
> 状态：🟢 未触发 / 🟡 已部分触发 / 🔴 已发生需处理 / ✅ 已闭环。

---

## 1. 采集与数据风险

| ID | 风险 | 影响 | 概率 | 缓解措施 | 状态 |
|----|------|------|------|---------|------|
| R1 | 竞品官网为 SPA，requests 拿不到内容 | 采集失败、缺口无法关闭 | 高 | M2 引入 Playwright；SourceSelector 按 L4 成功率自动升级 | 🟢 |
| R2 | 反爬 / IP 封禁 | 采集中断 | 中 | ToolGuard 速率限制、缓存命中优先、User-Agent、低并发、失败降级 | 🟢 |
| R3 | 页面结构变更导致解析失效 | 字段提取错误 | 高 | 解析器版本化 + 变更探测 + evolution_memory 记录失效源 | 🟢 |
| R4 | 数据源不可用（官网 404 / API 限流） | 缺口无法关闭 | 中 | 降级链（官网→缓存→替代源）；缺口标记 pending 而非编造 | 🟢 |
| R5 | 抓取内容语言混杂（中/英/日） | 提取质量下降 | 中 | 分析器指定目标语言；evaluation 用例覆盖多语言 | 🟢 |

## 5. 监控与处置流程

1. **登记**：新风险发生时登记本表（ID 递增），写明影响/概率/缓解。
2. **触发**：某风险实际发生 → 状态置 🟡，按缓解措施处理。
3. **闭环**：处理完成 → 状态置 ✅，记录处置结果。
4. **评审**：每个里程碑验收时评审一次本表。
