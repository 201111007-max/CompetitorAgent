# 7.38 版本补丁说明

## 综合改动

### 地图改动
- **新增传送门**: 地图四个角落新增传送门，连接优势路和劣势路
- **莲花池**: 地图新增莲花池，7:00 开始每 3 分钟刷新
- **智慧符**: 新增智慧符（Wisdom Rune），提供经验值
- **野区调整**: 野点位置调整，新增中立生物类型

### 机制改动
- **护甲公式调整**: 护甲减免公式优化，高护甲收益略微降低
- **魔抗叠加**: 魔抗叠加规则不变，新增部分魔抗装备
- **中立物品**: 新增 5 级中立物品，调整部分物品效果
- **Roshan 掉落**: 第三次击杀掉落刷新球碎片 + 奶酪

## 英雄改动

### 增强英雄
- **幽鬼 (Spectre)**: 荒芜伤害提升，折射范围增加
- **帕吉 (Pudge)**: 肉钩伤害提升，腐烂减速效果增强
- **影魔 (Shadow Fiend)**: 影压伤害提升，灵魂收集上限增加

### 削弱英雄
- **敌法师 (Anti-Mage)**: 法力护盾效果降低，闪烁 CD 增加
- **斯拉克 (Slark)**: 黑暗契约伤害降低，被动层数上限减少
- **宙斯 (Zeus)**: 雷击伤害降低，静电场范围缩小

### 重做英雄
- **工程师 (Techies)**: 技能重做，回归传统埋雷玩法
- **虚空假面 (Faceless Void)**: 时间结界效果调整，新增被动

## 装备改动

### 新增装备
- **永恒之盘 (Eternal Shroud)**: 魔抗 + 技能吸血
- **浩劫之锤 (Havoc Hammer)**: 范围眩晕主动效果

### 调整装备
- **黑皇杖 (BKB)**: 持续时间从 10/9/8/7/6/5 改为 9/8/7/6/5/4
- **闪烁匕首 (Blink Dagger)**: 受到英雄伤害后 CD 从 3 秒改为 4 秒
- **撒旦之邪力 (Satanic)**: 主动效果持续时间从 5 秒改为 4.5 秒
