# 护甲机制详解

## 基础公式

### 物理伤害减免
```
有效生命值 = 生命值 × (1 + 护甲 × 0.06)
物理减免 = (护甲 × 0.06) / (1 + 护甲 × 0.06)
```

### 护甲阈值
| 护甲值 | 物理减免 | 有效生命倍率 |
|--------|---------|-------------|
| 0      | 0%      | 1.0x        |
| 5      | 23%     | 1.3x        |
| 10     | 37.5%   | 1.6x        |
| 20     | 54.5%   | 2.2x        |
| 30     | 64.3%   | 2.8x        |
| 40     | 70.6%   | 3.4x        |

### 负护甲
负护甲会增加受到的物理伤害：
```
伤害加深 = 1 - (0.94)^(-护甲)
```
例如 -5 护甲 = 26.6% 额外物理伤害，-20 护甲 = 71% 额外物理伤害。

## 减甲手段

### 技能减甲
- **复仇之魂 (Vengeful Spirit)**: 恐怖波动 (-3/4/5/6 护甲)
- **影魔 (Shadow Fiend)**: 魔王降临 (-3/4/5/6 护甲)
- **潮汐猎人 (Tidehunter)**: 巨浪 (-3/4/5/6 护甲)
- **鱼人守卫 (Slardar)**: 侵蚀雾霭 (-8/12/16/20 护甲)
- **暗影恶魔 (Shadow Demon)**: 剧毒之触 (-3/4/5/6 护甲)

### 装备减甲
- **黯灭 (Desolator)**: -6 护甲（攻击时）
- **勇气勋章 (Medallion of Courage)**: -6 护甲（对目标）
- **炎阳纹章 (Solar Crest)**: -10 护甲（对目标）

## 护甲叠加规则
- 所有减甲效果线性叠加
- 多个减甲技能可以叠加到极高的负护甲
- 减甲对 Roshan 效果减半

## 实战应用
1. **推塔**: 减甲对建筑无效，推塔需要攻城伤害
2. **打 Roshan**: 减甲效果减半，但依然有效
3. **针对高护甲英雄**: 黯灭 + 勇气勋章可以大幅降低对方护甲
4. **前期**: 减甲在前期效果更明显，因为基础护甲低
