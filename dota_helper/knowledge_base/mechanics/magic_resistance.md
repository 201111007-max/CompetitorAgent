# 魔法抗性机制详解

## 基础公式

### 魔法伤害减免
```
实际魔法伤害 = 技能伤害 × (1 - 魔法抗性)
魔法抗性 = 1 - (1 - 基础抗性) × (1 - 物品抗性) × (1 - 技能抗性)
```

### 基础魔抗
| 英雄类型 | 基础魔抗 |
|---------|---------|
| 力量英雄 | 25%     |
| 敏捷英雄 | 25%     |
| 智力英雄 | 25%     |
| 小兵/野怪 | 0%      |
| Roshan   | 30%     |

## 魔抗叠加计算

魔抗不是简单相加，而是乘法叠加：
```
总魔抗 = 1 - (1 - 0.25) × (1 - 0.20) × (1 - 0.30)
       = 1 - 0.75 × 0.80 × 0.70
       = 1 - 0.42
       = 58%
```

## 魔法伤害类型

### 纯粹伤害
- 无视魔抗和护甲
- 例如：幽鬼的荒芜、斧王的淘汰之刃
- 计算公式：技能基础伤害

### 物理伤害技能
- 受护甲影响，不受魔抗影响
- 例如：剑圣的无敌斩、拍拍熊的激怒

### 魔法伤害技能
- 受魔抗影响
- 大多数技能属于此类

## 降低魔抗的手段

### 技能
- **维萨吉 (Visage)**: 灵魂超度 (-20% 魔抗)
- **上古巨神 (Elder Titan)**: 自然秩序 (-100% 基础魔抗)
- **天怒法师 (Skywrath Mage)**: 上古封印 (-18/22/26/30% 魔抗)

### 装备
- **纷争面纱 (Veil of Discord)**: -18% 魔抗（范围）
- **大根 (Dagon)**: 高额魔法爆发

## 实战应用
1. **针对高魔抗**: 出纷争面纱或选减魔抗英雄
2. **针对低魔抗**: 选高爆发法师英雄
3. **推塔**: 魔法伤害对建筑无效
4. **Roshan**: 30% 基础魔抗，需要物理输出
