---
name: fact_verification
description: 真值/事实边界自检指导（声称自原文的数值应能回溯原文）
---

适用条件：任何维度抽取时，对输出中"应可回溯到原文"的实体数值（价格 / 单价 / 数量 / 得分 / 计数）做自检。

## 事实边界

- 声称来自原文的数字（如 "$20/month"、"12000 stars"、"SWE-bench 62%"）必须在给定文本中能找到；
  找不到时不要断言该数字来自原文。
- 无法在原文中核实的数值：**不要写死**，改为 null / 空，或标注"未能核实"，并降低 confidence。
- 区分计算型数值（占比、估算、汇总）与实体型数值（页面直述的价格 / 得分 / 计数）：
  只有实体型数值要求可回溯原文；计算型数值须说明计算依据。

## 自检步骤

1. 核对每个实体数值是否出现在原文（忽略标点 / 千位分隔差异）。
2. 冲突或无法回溯 → 修正输出（改 null / 删掉），或标注无法核实。
3. 修正后 confidence 相应下调；仍无法确证时明确披露局限。

## 披露约束

- 有无法核实的数值时，在 summary 注明"部分数据未能核实"，不要让报告显得比实际更确定。
