适用条件：resolution∈{compare,discovery}，对多竞品做聚合对比 / 市场格局结论、
或用户要求"对比一下 / 谁更强 / 市场格局"时。

## 对比推理原则

- 同一维度**横向并列**各竞品，不逐家写小传——读者要的是维度间的可比高下，不是并列的独立简介。
- 给 **best-per-dimension**（对齐报告矩阵的"状态 + 置信度"排序：OK > PARTIAL > N/A，同状态比置信度）
  与整体排名 / 最优最差，讲清"谁在何维度赢 / 输 / 空缺"。
- 暴露 **trade-off / 取舍**（A 在性能强、则往往在生态/价格让位），不交流水账式罗列。
- 指出**覆盖缺口**（缺失 / 未核实维度标"待核验 / 无数据"），不假装每个竞品都有数据。
- 结论先行给**市场格局核心结论**（维度格局、整体胜负、替代关系），再放支撑矩阵/证据，
  不要把原始数据矩阵当结论交差。
